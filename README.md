# Что? Где? Когда? Шпаргалка

Это улучшенное веб-приложение предоставляет удобный способ просмотра и поиска по вопросам популярной интеллектуальной игры "Что? Где? Когда?".

## Особенности

- 🎨 Современный адаптивный дизайн с возможностью переключения между светлой и темной темами
- 🔍 Мощная система поиска по вопросам, ответам и темам
- 📚 Страница с возможностью настройки количества отображаемых вопросов
- 🔄 Сортировка по дате и теме
- 🖼️ Поддержка изображений в вопросах
- 📱 Полностью адаптивный интерфейс для всех устройств
- ⚡ Плавные анимации и переходы
- 🌙 Возможность сохранения выбранной темы

## Установка

1. Клонируйте репозиторий:
```
git clone <repo-url>
cd what-where-when-cheat-sheet
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Запустите приложение:
```
python app.py
```

4. Откройте браузер и перейдите по адресу `http://localhost:5001`

## Использование

- Используйте строку поиска для поиска по любым полям вопросов
- Настройте количество вопросов на странице с помощью выпадающего списка
- Сортируйте вопросы по дате или теме
- Переключайтесь между светлой и темной темой с помощью кнопки в правом верхнем углу заголовка
- Нажмите "Показать ответ", чтобы открыть ответ на вопрос

## Технологии

- Python/Flask (серверная часть)
- SQLite (база данных)
- HTML/CSS/JavaScript (клиентская часть)
- Адаптивный дизайн без использования фреймворков
